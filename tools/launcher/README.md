# Launcher

One-press launch for **THE HUB** (`hub/index.html`), which embeds the brush
designer and reads `dashboard.json` + `state/vault_manifest.json`. Those fetches
need an HTTP origin, so the launcher starts a loopback-only static server on the
repo root before opening the browser.

| File | What it does |
| --- | --- |
| `Start-Hub.ps1` | Starts the server (reusing one that's already up) and opens `http://localhost:8765/hub/` |
| `Install-Shortcut.ps1` | Generates `hub.ico` and writes the Desktop + Start Menu shortcuts |
| `hub.ico` | Generated by the installer — safe to delete, it gets rebuilt |

## Install

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-Shortcut.ps1
```

Then right-click the Desktop **Studio Hub** icon and choose **Pin to taskbar** —
Windows has blocked scripted pinning since 1809, so that click is manual and
only needed once. The Start Menu copy carries a **Ctrl+Alt+H** hotkey.

## Notes

- The server binds `127.0.0.1` only; nothing is exposed to the network.
- It stays up after the browser closes. Shut it down with
  `.\Start-Hub.ps1 -Stop`.
- Ports `8765-8774` are probed in order; `-Port` overrides the start of that range.
- It runs `python.exe`, not `pythonw.exe`: `http.server` logs each request to
  stderr, which is `None` under `pythonw`, and every connection dies on that.
